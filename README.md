# FlexLab

Site institucional de uma academia fictícia, desenvolvido como uma página única para apresentar a empresa, seus diferenciais, planos e canais de contato.

## Sobre o projeto

O FlexLab foi criado como uma atividade prática de desenvolvimento colaborativo com Git e GitHub. O site reúne quatro partes principais em uma única página responsiva:

- header, menu de navegação e seção inicial;
- apresentação da academia;
- serviços e planos;
- contato, formulário demonstrativo e rodapé.

## Funcionalidades

- navegação entre as seções da página;
- apresentação dos diferenciais da FlexLab;
- cards com planos da academia;
- formulário visual de contato;
- layout responsivo para diferentes tamanhos de tela;
- recursos básicos de acessibilidade.

> O formulário é demonstrativo e não envia ou armazena dados.

## Tecnologias

- HTML5;
- CSS3;
- Git;
- GitHub.

O projeto não utiliza JavaScript, Python ou serviços de back-end.

## Fluxo de colaboração

Cada integrante trabalhou em sua própria branch, realizou commits e enviou as alterações por Pull Request. Após as revisões e a resolução dos conflitos, as contribuições foram integradas à branch `main`.
